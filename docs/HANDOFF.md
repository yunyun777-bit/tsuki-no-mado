## 実装と検証の進め方

Node.js 22以上。外部npm依存・ビルド・APIキー不要です。

```sh
npm run check
npm run preview
npm run package
```

- `check`: manifest、配布対象の参照、JS構文、自動テストを検査。対象が限定できる場合は先に該当する `node --test tests/<対象>.test.js` を実行してよい。
- `preview`: `http://127.0.0.1:4173/newtab.html`。起動済みなら同じポートへ二重起動しない。サンプルデータのみで、再読み込みすると編集がリセットされる。履歴API・永続保存・Chromeの権限UIは検証できない。
- `package`: 新しい配布フォルダーを `dist/` に作成。既存の読み込み元は自動更新されない。対象一覧は `scripts/release.js` を参照し、ファイル数を固定値で仮定しない。ロゴ追加後はサブディレクトリも含む。
- 表示を変更したら影響する画面・幅・設定を確認。実Chromeの項目は `docs/TESTING.md`、実施済みの範囲は `docs/VALIDATION.md` に記録する。
