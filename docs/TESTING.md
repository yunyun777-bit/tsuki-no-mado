# Chromeでの確認手順

この文書は手動テスト手順です。チェック欄は実行後にのみ埋めてください。自動テストやブラウザープレビューでは、Chrome自身の権限UI・Service Worker・再起動後の動作は確認できません。

## 準備

1. `npm run check` と `npm run package` を実行します。
2. 普段の閲覧データがないテスト用Chromeプロファイルを使用します。
3. `chrome://extensions` でデベロッパーモードを有効にし、出力された配布用フォルダーを読み込みます。
4. Chromeのバージョン、OS、テストしたコードのコミットまたは配布物名を記録します。

## 必須の確認

- [ ] 新規タブのタイトルと画面に「月の窓」が表示され、副題がない。
- [ ] 訪問済みのサイトについて、おすすめ・固定・ショートカットにサイトアイコンが表示される。アイコン取得エラー時は頭文字が残り、壊れた画像にならない。Chromeに保存がない場合は標準アイコンになることがある。
- [ ] 初回は空状態。履歴の許可は「履歴を使って始める」を押すまで出ない。
- [ ] 履歴を拒否してもサイトの手動追加・固定・非表示が使える。
- [ ] example.comとexample.orgを訪問後、履歴を許可すると候補になる。ページのパスはカードに出ない。
- [ ] 学習停止で履歴権限が取り消され、その後の訪問が学習されない。既存候補は残る。
- [ ] 再開で学習できる。Chromeを再起動してもサイト・固定・ショートカット・背景が残る。
- [ ] Chromeの拡張管理から履歴権限を外すと学習が停止する。
- [ ] 学習有効中にテスト用Chromeの履歴を削除すると訪問記録が消える。手動追加・固定は残る。
- [ ] アドレスバーで設定した既定の検索サービスに検索語が渡る。URL入力は指定ページに移動する。
- [ ] ショートカットの追加・編集・移動・削除・取り消しが機能する。
- [ ] ライト・ダーク・システム連動、背景色、ローカル画像の選択・削除が機能する。
- [ ] 保存済みの背景色・画像が更新後も変わらない。「時間に合わせる」を選ぶと時刻に応じた空と月の形が表示され、明るさ「自動」では昼夜に連動する。
- [ ] カードのマウス操作時に軽く浮き上がり、OSの動きを減らす設定では移動・拡大が止まる。
- [ ] 「時間に合わせる」で背景の光・星・流れ星が動き、月が上下する。「背景や月を動かす」をオフにすると常時の動きが止まり、別の新規タブでも設定が残る。
- [ ] カードの登場演出は新規タブの初回表示だけ。サイトの絞り込みでは繰り返さない。OSの動きを減らす設定では登場演出と背景・月の動きが止まる。
- [ ] Tabキーで主要操作に到達でき、フォーカスが見える。Escでダイアログを閉じられる。
- [ ] 設定の全データ削除で拡張の設定が初期化され、Chrome自身の履歴は残る。
- [ ] シークレットモードでは拡張が無効になっている。
- [ ] 拡張管理画面とService Workerコンソールにエラーがない。
- [ ] ネットワークパネルで、新規タブを表示しただけでは外部へ通信しない。検索・リンク操作時の遷移は別。

## 更新確認

同じフォルダーの拡張を再読み込みし、保存済みデータが残ることを確認します。新しいフォルダーを別拡張として読み込むテストは、更新テストの代わりにはなりません。

## 0.4.0の追加確認

- 更新前のショートカットが「いつもの」に入り、完全なURL・背景・履歴・設定が保たれる。
- グループの追加・名前変更・切替、別グループへのショートカット移動、各10件の上限、空グループ削除を確認。再起動後も最後のグループを保持する。
- 「今日中」「1週間」の一時非表示中も訪問記録を保持・学習し、期限または設定からの解除で候補に戻る。
- バックアップをダウンロードし、実ファイルに訪問時刻や学習権限が含まれないことを確認。読み込み確認でキャンセルすると状態が変わらず、復元すると対象設定だけが置き換わる。不正JSON・危険なURL・壊れた画像は拒否する。
- おすすめ4・8・12件、固定／おすすめの折りたたみ、一行メモの保存・消去・非表示を確認。再起動後の保存と、複数タブ切替時の反映を確認。
- キーボード・ポインター操作、狭い画面、明暗表示、動きを減らす設定で利用できる。
